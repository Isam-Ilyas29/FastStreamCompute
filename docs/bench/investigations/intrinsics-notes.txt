FastStreamCompute temporary intrinsics investigation - 2026-09-30
No project files modified. Windows laptop, CPU 2 thread affinity, GCC 16.2.
Common flags: -O3 -DNDEBUG -std=c++20 -fno-fast-math -ffp-contract=off; no LTO.
Baseline: original executor, generic x86-64. AVX variants: GCC target("avx2").
All executor definitions and blueprint accessors visible in the same translation unit in fair.cpp/fair2.cpp.
ManualAVX2Hoisted replaces eight arithmetic loops with unaligned four-double AVX operations; row pointers computed outside loops; scalar remainder; no FMA.
AutoAVX2NoAlias adds #pragma GCC ivdep to arithmetic loops only; safety relies on distinct destination rows from valid Program nodes.
Correctness: reference equality on finite generated data, fusion on/off, capacities 1/3/4/7/64/256, counts 0/1/3/4/5/63/64/65/255/256/257/845, executor reuse, separate multiple outputs.
Timed calls include loads, scratch arithmetic and output copying. Preparation and reference checking outside timing.
final-results.json: 15 random-interleaved repetitions, minimum 0.1s. 480 raw measurements, zero benchmark errors.
confirmation.json: 20 repetitions, minimum 0.15s, PriceRatio and Polynomial / 65536 / 256. 160 raw measurements, zero benchmark errors.
CAUTION: many CVs exceed 20%; confirmation CVs 24-44%. Small differences and exact speedup estimates are not reliable.
Initial results.json excluded: unequal compiler visibility for variants. fair-results.json used corrected visibility but naive ManualAVX2 still did repeated address calculations in vector loops.
