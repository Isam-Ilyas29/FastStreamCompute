FUSION BENCHMARK RESULTS

20 randomly interleaved repetitions.
Comparisons use median real time.
Chunk capacity: 256 records.

INTERPRETATION

Fusion reduced median execution time by approximately 41% at both input
sizes, corresponding to approximately 1.7x throughput.

At 4,096 records, fusion saved 9,098 ns per execution. Median long-program
creation and destruction time increased by 75 ns. These measurements
suggest that the additional preparation cost is recovered within the
first execution of this workload.

The creation benchmark includes blueprint construction, chunked executor
construction, scratch allocation and destruction. The Program is built
outside timing. The comparison measures the net effect of enabling fusion
on this lifecycle; it does not isolate the fusion loop itself.

Median preparation time increased by 75 ns for the long program and
45 ns for midpoint. Preparation measurements were noisier, so these small
differences should be treated as approximate rather than precise costs.

The execution improvement is stronger evidence: it appears at both input
sizes, has real-time CV between 2.03% and 3.53%, and produces similar
speedup ratios. These results apply to this workload and machine.
